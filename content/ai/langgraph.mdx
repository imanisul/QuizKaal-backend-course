## Why LangGraph?

LangChain chains are **linear** — data flows in one direction. But real AI workflows need:

- **Cycles:** Retry a step if it fails
- **Branching:** Route to different paths based on intermediate results
- **State:** Persist data across steps
- **Human-in-the-loop:** Pause and wait for human approval

LangGraph models workflows as a **directed graph** — nodes are functions, edges define the flow, and state is passed between them.

## Core Concepts

### State

A shared object that every node can read and update:

```javascript
import { Annotation } from "@langchain/langgraph";

// Define the state schema
const GraphState = Annotation.Root({
  messages: Annotation({ 
    reducer: (prev, next) => [...prev, ...next],
    default: () => [] 
  }),
  documents: Annotation({ default: () => [] }),
  question: Annotation({ default: () => "" }),
  generation: Annotation({ default: () => "" }),
  retryCount: Annotation({ default: () => 0 }),
});
```

### Nodes

Functions that take state as input and return updated state:

```javascript
// Node: Retrieve relevant documents
async function retrieve(state) {
  const documents = await retriever.invoke(state.question);
  return { documents };
}

// Node: Generate an answer
async function generate(state) {
  const context = state.documents.map(d => d.pageContent).join("\n");
  const response = await model.invoke(`
    Context: ${context}
    Question: ${state.question}
    Answer:
  `);
  return { generation: response.content };
}

// Node: Grade the answer
async function gradeAnswer(state) {
  const grade = await model.invoke(`
    Is this answer grounded in the documents?
    Answer: ${state.generation}
    Documents: ${state.documents.map(d => d.pageContent).join("\n")}
    Respond: "good" or "bad"
  `);
  return { answerGrade: grade.content.trim() };
}
```

### Edges and Conditional Routing

```javascript
import { StateGraph, END } from "@langchain/langgraph";

const workflow = new StateGraph(GraphState)
  // Add nodes
  .addNode("retrieve", retrieve)
  .addNode("generate", generate)
  .addNode("grade_answer", gradeAnswer)
  .addNode("rewrite_query", rewriteQuery)
  
  // Define the flow
  .addEdge("__start__", "retrieve")
  .addEdge("retrieve", "generate")
  .addEdge("generate", "grade_answer")
  
  // Conditional edge: if answer is bad, rewrite the query and retry
  .addConditionalEdges("grade_answer", (state) => {
    if (state.answerGrade === "good") return END;
    if (state.retryCount >= 3) return END; // Prevent infinite loops
    return "rewrite_query";
  })
  
  // After rewriting, loop back to retrieve
  .addEdge("rewrite_query", "retrieve");

const app = workflow.compile();

// Run the graph
const result = await app.invoke({ 
  question: "How does Redis handle cache invalidation?" 
});
```

## Human-in-the-Loop

For high-stakes operations, pause the graph and wait for human approval:

```javascript
import { MemorySaver } from "@langchain/langgraph";

const checkpointer = new MemorySaver();

const workflow = new StateGraph(GraphState)
  .addNode("draft_email", draftEmail)
  .addNode("send_email", sendEmail)
  .addEdge("__start__", "draft_email")
  // Interrupt BEFORE sending — wait for human approval
  .addEdge("draft_email", "send_email");

const app = workflow.compile({
  checkpointer,
  interruptBefore: ["send_email"], // Pause here!
});

// Run until interruption
const config = { configurable: { thread_id: "email-123" } };
const state = await app.invoke(
  { question: "Draft a follow-up email to the client" },
  config
);

console.log(state.draftEmail); // Show draft to human

// After human approves, resume
await app.invoke(null, config); // Continues from where it paused
```

## Real-World Example: Research Agent

```javascript
const researchGraph = new StateGraph(GraphState)
  .addNode("plan", async (state) => {
    const plan = await model.invoke(
      `Create a research plan for: ${state.question}`
    );
    return { plan: plan.content };
  })
  .addNode("search", async (state) => {
    const results = await tavilySearch.invoke(state.currentStep);
    return { searchResults: results };
  })
  .addNode("analyze", async (state) => {
    const analysis = await model.invoke(
      `Analyze these search results: ${state.searchResults}`
    );
    return { analysis: analysis.content };
  })
  .addNode("write_report", async (state) => {
    const report = await model.invoke(
      `Write a report based on: ${state.analyses.join("\n")}`
    );
    return { finalReport: report.content };
  })
  .addEdge("__start__", "plan")
  .addConditionalEdges("plan", routeToSearch) // Loop through plan steps
  .addEdge("search", "analyze")
  .addConditionalEdges("analyze", (state) => {
    if (state.stepsRemaining > 0) return "search"; // Next step
    return "write_report"; // All steps done
  })
  .addEdge("write_report", END);
```
