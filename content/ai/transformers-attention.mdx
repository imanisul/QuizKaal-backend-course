## The Problem Before Transformers

Before 2017, language models used **Recurrent Neural Networks (RNNs)** and **LSTMs**. They processed text **one word at a time**, left to right. This had two critical problems:

1. **Slow:** You can't parallelize sequential processing
2. **Forgetful:** By the time the model reaches word 500, it has mostly forgotten word 1

## The Transformer Architecture

In 2017, Google published the paper **"Attention Is All You Need"** and changed AI forever. The Transformer processes all words in a sentence **simultaneously** using a mechanism called **Self-Attention**.

### The Building Blocks

A Transformer has two main components:

- **Encoder:** Reads and understands the input (used by BERT)
- **Decoder:** Generates output text (used by GPT)

GPT models (ChatGPT) use **decoder-only** Transformers. BERT uses **encoder-only**. Translation models (like Google Translate) use **both**.

## Self-Attention: The Core Innovation

Self-Attention allows each word in a sentence to look at **every other word** and decide how much to "pay attention" to it.

Consider: _"The animal didn't cross the street because **it** was too tired."_

What does **"it"** refer to? The animal or the street? Humans know instantly — the animal. Self-Attention learns this by computing attention scores between every pair of words.

### Step by Step

For each word, the model creates three vectors:

- **Query (Q):** "What am I looking for?"
- **Key (K):** "What do I contain?"
- **Value (V):** "What information do I provide?"

```javascript
// Simplified Self-Attention in JavaScript
function selfAttention(embeddings) {
  const Q = matMul(embeddings, W_query); // What am I looking for?
  const K = matMul(embeddings, W_key);   // What do I contain?
  const V = matMul(embeddings, W_value); // What info do I carry?
  
  // How much should each word attend to every other word?
  const scores = matMul(Q, transpose(K));
  
  // Scale to prevent exploding gradients
  const d_k = K[0].length;
  const scaledScores = scores.map(row => 
    row.map(val => val / Math.sqrt(d_k))
  );
  
  // Softmax → convert to probabilities
  const attentionWeights = scaledScores.map(softmax);
  
  // Weighted sum of values
  const output = matMul(attentionWeights, V);
  return output;
}
```

### Multi-Head Attention

Instead of computing attention once, Transformers compute it **multiple times in parallel** (8-96 "heads"). Each head can learn a different type of relationship:

- Head 1 might learn **syntax** (subject-verb agreement)
- Head 2 might learn **coreference** (what "it" refers to)
- Head 3 might learn **semantic similarity**

## Positional Encoding

Since Transformers process all words simultaneously (not sequentially like RNNs), they have no inherent sense of word order. **Positional encodings** are added to each word's embedding to encode its position in the sentence.

```javascript
// Sinusoidal positional encoding
function positionalEncoding(position, d_model) {
  const encoding = new Array(d_model);
  for (let i = 0; i < d_model; i++) {
    if (i % 2 === 0) {
      encoding[i] = Math.sin(position / Math.pow(10000, i / d_model));
    } else {
      encoding[i] = Math.cos(position / Math.pow(10000, (i - 1) / d_model));
    }
  }
  return encoding;
}
```

## GPT vs BERT: Decoder vs Encoder

| Feature | GPT (Decoder) | BERT (Encoder) |
|---------|--------------|----------------|
| **Direction** | Left-to-right (causal) | Bidirectional |
| **Training** | Predict next token | Predict masked tokens |
| **Strength** | Text generation | Text understanding |
| **Used by** | ChatGPT, Claude, Gemini | Search engines, classification |
| **Attention** | Masked (can't see future) | Full (sees all words) |

## Tokenization

Before text enters a Transformer, it's broken into **tokens**. Tokens are not always full words:

```
"unhappiness" → ["un", "happiness"]
"ChatGPT"     → ["Chat", "G", "PT"]
"🚀"          → ["🚀"]
```

**Why tokens matter for engineers:**
- GPT-4 has a context window of ~128K tokens
- Each API call is billed per token
- Prompt engineering is fundamentally about efficient token usage

## The Scale of Modern LLMs

| Model | Parameters | Training Data | Context Window |
|-------|-----------|---------------|----------------|
| GPT-3 | 175B | 570GB text | 4K tokens |
| GPT-4 | ~1.8T (estimated) | ~13T tokens | 128K tokens |
| Claude 3.5 | Unknown | Unknown | 200K tokens |
| Llama 3 | 70B | 15T tokens | 8K tokens |

> **Key Insight:** More parameters = more patterns the model can learn. But training a 175B parameter model costs **$4-12 million** in compute.
