## The Single Agent Bottleneck

A single ReAct agent struggles with complex tasks (like "Write a 10-page market research report") because:

1. **Context Bloat:** The prompt gets too large with instructions for researching, writing, and formatting.
2. **Tool Overload:** Giving one agent 20 different tools confuses it. It picks the wrong tools or hallucinates arguments.
3. **Loss of Focus:** It forgets the original goal halfway through execution.

## Multi-Agent Patterns

### 1. The Supervisor Pattern

One "Manager" agent routes tasks to specialized "Worker" agents.

```
                  ┌──────────────┐
                  │  Supervisor  │
                  │   (Router)   │
                  └──────┬───────┘
                         │
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  Researcher  │  │    Writer    │  │  QA Checker  │
│  (Web Search)│  │ (Formatting) │  │  (Validation)│
└──────────────┘  └──────────────┘  └──────────────┘
```

The Supervisor decides *who* should act next. When a worker finishes, control returns to the Supervisor.

### 2. The Network (Peer-to-Peer) Pattern

Agents talk directly to each other without a central manager. Useful for debates or brainstorming.

### 3. The Hierarchical Pattern

Supervisors managing other Supervisors (e.g., A "Tech Lead" agent managing "Frontend" and "Backend" agents, reporting to a "Product Manager" agent).

## Building a Supervisor with LangGraph

LangGraph is perfectly suited for multi-agent systems because agents are just nodes in a state graph.

```javascript
import { StateGraph, END } from "@langchain/langgraph";
import { ChatOpenAI } from "@langchain/openai";

const model = new ChatOpenAI({ model: "gpt-4" });

// 1. Define the Team State
// This is the shared whiteboard all agents can read/write
const TeamState = {
  messages: [],       // Conversation history
  nextAgent: "",      // Who goes next?
  researchData: "",   // Data collected by researcher
  draftReport: "",    // Report written by writer
};

// 2. Define the Supervisor Node
async function supervisorNode(state) {
  const prompt = `
    You are a manager. Your team has two workers: "Researcher" and "Writer".
    Given the conversation so far, who should act next?
    If the task is complete, reply "FINISH".
    
    Conversation: ${state.messages.join("\n")}
    
    Reply ONLY with: "Researcher", "Writer", or "FINISH".
  `;
  
  const response = await model.invoke(prompt);
  return { nextAgent: response.content.trim() };
}

// 3. Define the Worker Nodes
async function researcherNode(state) {
  // Agent logic with web search tools...
  const data = await runResearchAgent(state.messages);
  return { researchData: data, messages: [...state.messages, "Research complete"] };
}

async function writerNode(state) {
  // Agent logic with writing tools...
  const report = await runWriterAgent(state.researchData);
  return { draftReport: report, messages: [...state.messages, "Draft written"] };
}

// 4. Build the Graph
const workflow = new StateGraph({ channels: TeamState })
  .addNode("supervisor", supervisorNode)
  .addNode("Researcher", researcherNode)
  .addNode("Writer", writerNode)
  
  // The supervisor decides who goes next
  .addConditionalEdges("supervisor", (state) => {
    if (state.nextAgent === "FINISH") return END;
    return state.nextAgent;
  })
  
  // Workers always report back to the supervisor
  .addEdge("Researcher", "supervisor")
  .addEdge("Writer", "supervisor")
  .addEdge("__start__", "supervisor");

const team = workflow.compile();
```

## Frameworks Comparison

| Framework | Architecture | Best For |
|-----------|-------------|----------|
| **LangGraph** | Graph-based state machine | Production systems requiring strict control, cycles, and custom logic |
| **CrewAI** | Role-based (Crew, Tasks, Agents) | Fast prototyping, simple sequential or hierarchical tasks |
| **AutoGen** | Conversational (Agents talk to each other) | Multi-agent debates, code generation and execution |

### Why LangGraph Wins in Production

CrewAI and AutoGen are easier to set up, but they are **black boxes**. When a CrewAI agent gets stuck in a loop, it's hard to intervene. LangGraph forces you to define the edges and state explicitly, giving you absolute control over the workflow, state persistence, and human-in-the-loop interventions.
