## What is LangChain?

LangChain is an **open-source framework** for building applications powered by Large Language Models (LLMs). It provides standardized interfaces to connect:

- **Prompts** → **Models** → **Output Parsers** → **Tools** → **Memory**

<AnalogyCard
  title="The Assembly Line Analogy"
  description="Think of LangChain as a factory assembly line. Raw materials (user input) enter the line, pass through multiple stations (prompt template → LLM → parser → database lookup → another LLM), and come out as a finished product (structured response). LCEL is the conveyor belt that connects each station."
/>

### Why Not Just Call the OpenAI API Directly?

You can, but LangChain solves common problems:

| Problem | LangChain Solution |
|---------|-------------------|
| Switching between GPT-4 and Claude | Unified model interface |
| Formatting prompts consistently | PromptTemplates |
| Parsing JSON from LLM responses | OutputParsers |
| Connecting LLMs to databases | Retrievers + Chains |
| Maintaining conversation history | Memory modules |
| Calling external APIs | Tool/Agent framework |

## LCEL: LangChain Expression Language

LCEL is a **declarative pipe syntax** for composing chains. It uses the `|` (pipe) operator to connect components, just like Unix pipes.

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { StringOutputParser } from "@langchain/core/output_parsers";

// Define each component
const prompt = ChatPromptTemplate.fromTemplate(
  "Explain {topic} to a 5-year-old in 2 sentences."
);

const model = new ChatOpenAI({ 
  model: "gpt-4",
  temperature: 0.7 
});

const parser = new StringOutputParser();

// LCEL: Pipe them together
const chain = prompt.pipe(model).pipe(parser);

// Run the chain
const result = await chain.invoke({ topic: "quantum computing" });
console.log(result);
// "Imagine you have a magic coin that can be heads AND tails 
//  at the same time. Quantum computers use these magic coins 
//  to solve really hard puzzles super fast!"
```

### How LCEL Works Under the Hood

Every LCEL component is a **Runnable** — an object with three methods:

- **`invoke(input)`** — Process a single input
- **`batch([inputs])`** — Process multiple inputs in parallel
- **`stream(input)`** — Stream the output token by token

When you pipe components with `|`, LCEL creates a `RunnableSequence` that passes the output of each step as input to the next.

## Building a Real Chain

Let's build a chain that takes a product description and generates a marketing email:

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { StructuredOutputParser } from "langchain/output_parsers";
import { z } from "zod";

// Step 1: Define structured output
const outputParser = StructuredOutputParser.fromZodSchema(
  z.object({
    subject: z.string().describe("Email subject line"),
    body: z.string().describe("Email body (2-3 paragraphs)"),
    cta: z.string().describe("Call-to-action button text"),
  })
);

// Step 2: Create the prompt
const prompt = ChatPromptTemplate.fromTemplate(`
  You are a senior copywriter. Write a marketing email for:
  Product: {product}
  Audience: {audience}
  
  {format_instructions}
`);

// Step 3: Build the chain
const model = new ChatOpenAI({ model: "gpt-4", temperature: 0.8 });

const chain = prompt.pipe(model).pipe(outputParser);

// Step 4: Run it
const email = await chain.invoke({
  product: "AI-powered code review tool",
  audience: "Senior engineers at FAANG companies",
  format_instructions: outputParser.getFormatInstructions(),
});

console.log(email.subject); // "Ship Faster, Break Nothing"
console.log(email.cta);     // "Start Free Trial →"
```

## Prompt Templates

LangChain provides several prompt template types:

```javascript
// Simple template
const simple = ChatPromptTemplate.fromTemplate(
  "Translate '{text}' to {language}"
);

// Multi-message template (for chat models)
const chat = ChatPromptTemplate.fromMessages([
  ["system", "You are a {role}. Always respond in {format}."],
  ["human", "{question}"],
]);

// Few-shot template
const fewShot = FewShotChatMessagePromptTemplate.fromExamples(
  examples,    // Array of input/output pairs
  examplePrompt,
  "human",
  { inputVariables: ["input"] }
);
```

## RunnablePassthrough & RunnableParallel

For complex chains, you often need to pass data through unchanged or run multiple steps in parallel:

```javascript
import { RunnablePassthrough, RunnableParallel } from "@langchain/core/runnables";

// Run two chains in parallel and merge results
const analysisChain = RunnableParallel.from({
  sentiment: sentimentChain,
  summary: summaryChain,
  original: new RunnablePassthrough(), // Pass input through unchanged
});

const result = await analysisChain.invoke("I love this product but the shipping was terrible");
// {
//   sentiment: "mixed",
//   summary: "Positive product review with negative shipping experience",
//   original: "I love this product but the shipping was terrible"
// }
```
