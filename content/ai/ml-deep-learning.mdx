## What is Machine Learning?

Machine Learning is a subset of Artificial Intelligence where computers **learn patterns from data** instead of being explicitly programmed with rules.

  title="The Chef Analogy"
  description="Imagine teaching someone to cook. Traditional programming is like giving them a recipe (step-by-step instructions). Machine Learning is like giving them 1,000 meals to taste and letting them figure out the recipe themselves. The more meals they taste, the better they get at cooking."

### Three Types of ML

- **Supervised Learning:** You give the model labeled data (input → expected output). It learns the mapping. Example: "This email is spam" / "This email is not spam."
- **Unsupervised Learning:** You give the model unlabeled data and it finds hidden patterns. Example: Grouping customers by shopping behavior.
- **Reinforcement Learning:** The model learns through trial and error, receiving rewards for correct actions. Example: Training an AI to play chess.

## What is Deep Learning?

Deep Learning is a subset of ML that uses **neural networks with many layers** (hence "deep"). It powers everything from ChatGPT to self-driving cars.

### The Neuron (Perceptron)

A single artificial neuron does three things:

1. **Receives inputs** (numbers), each multiplied by a **weight**
2. **Sums them up** and adds a **bias**
3. **Passes the result through an activation function** to produce output

```javascript
// A single neuron in JavaScript
function neuron(inputs, weights, bias) {
  let sum = 0;
  for (let i = 0; i < inputs.length; i++) {
    sum += inputs[i] * weights[i];
  }
  sum += bias;
  
  // ReLU activation function
  return Math.max(0, sum);
}

// Example: Is this email spam?
const features = [0.8, 0.2, 0.9]; // [hasLinks, isFromContact, hasSpamWords]
const weights  = [0.5, -0.7, 0.9]; // learned weights
const bias     = -0.3;

const output = neuron(features, weights, bias);
console.log(output > 0.5 ? "SPAM" : "NOT SPAM");
```

## Neural Network Architecture

A neural network stacks neurons into **layers**:

- **Input Layer:** Receives raw data (e.g., pixel values of an image)
- **Hidden Layers:** Transform the data through learned patterns (the "deep" in deep learning)
- **Output Layer:** Produces the final prediction

## Forward Propagation

Data flows **forward** through the network, layer by layer. Each neuron computes its weighted sum, applies an activation function, and passes the result to the next layer.

```javascript
// Simple 2-layer neural network (forward pass)
function forwardPass(input) {
  // Layer 1: 3 inputs → 2 hidden neurons
  const hidden1 = relu(dot(input, weightsLayer1) + biasLayer1);
  const hidden2 = relu(dot(input, weightsLayer2) + biasLayer2);
  
  // Layer 2: 2 hidden → 1 output
  const output = sigmoid(
    hidden1 * weightOutput1 + hidden2 * weightOutput2 + biasOutput
  );
  
  return output; // probability between 0 and 1
}
```

## Backpropagation: How Networks Learn

After a forward pass, the network compares its prediction to the actual answer. The difference is called the **loss**. Backpropagation calculates how much each weight contributed to the error and adjusts them accordingly.

1. **Calculate Loss:** How wrong was the prediction?
2. **Compute Gradients:** How much did each weight contribute to the error? (using calculus — chain rule)
3. **Update Weights:** Nudge each weight in the direction that reduces the error

This process repeats thousands of times. Each full pass through the data is called an **epoch**.

> **Pro Tip:** The "learning rate" controls how big each weight adjustment is. Too high → overshoots. Too low → takes forever to converge.

## Activation Functions

Activation functions introduce **non-linearity**, allowing networks to learn complex patterns:

| Function | Formula | Use Case |
|----------|---------|----------|
| **ReLU** | max(0, x) | Hidden layers (most common) |
| **Sigmoid** | 1/(1+e^-x) | Binary classification output |
| **Softmax** | e^xi / Σe^xj | Multi-class classification output |
| **Tanh** | (e^x - e^-x)/(e^x + e^-x) | Hidden layers (centered at 0) |
