## 1. The Journey of a Byte

<ConceptBlock type="idea" title="Overview">
  When you download a 5MB song, it doesn't travel through the internet as one giant 5MB file. It is shredded into thousands of tiny pieces, sent individually across the globe, and reassembled on your device.
</ConceptBlock>

The internet relies on **Packet Switching**. Instead of keeping a dedicated line open between two computers, data is chopped up into small chunks called **Packets** (typically around 1500 bytes each).

<AnalogyCard title="Mailing a Bicycle">
  Imagine trying to mail a bicycle to your friend, but the post office only accepts small envelopes. You would have to disassemble the bike, put each piece in a separate envelope, number them (1 of 50, 2 of 50, etc.), and mail them all. They might arrive on different days, but your friend can use the numbers to rebuild it.
</AnalogyCard>

## 3. The Role of Routers

If packets are envelopes, **Routers** are the post offices.

When a packet leaves your laptop, it goes to your home Wi-Fi router. That router looks at the "Destination IP" on the packet and says: *"I don't know where this specific computer is, but I know it's in Europe. Let me pass this to a bigger router that handles transatlantic traffic."*

This process (called "routing") happens over and over again, bouncing the packet through 10-20 different routers across the world until it reaches its final destination.

## 4. Node.js Implementation: Data Chunks

In Node.js, we don't usually deal with raw network "packets" directly (the OS handles that). However, we deal with the exact same concept using **Streams** and **Buffers** (chunks of data). 

When a user uploads a large file to your Node.js server, Node.js doesn't wait for the entire file to arrive. It processes it in small "chunks"—just like packets!

<CodeTabs>
  <div label="uploadServer.js">
    ```javascript
    const http = require('http');
    const fs = require('fs');

    const server = http.createServer((req, res) => {
      if (req.method === 'POST') {
        let chunkCount = 0;
        
        // As packets (chunks) arrive over the network, this event fires
        req.on('data', (chunk) => {
          chunkCount++;
          console.log(`📦 Received chunk ${chunkCount}: ${chunk.length} bytes`);
        });

        // When all packets have arrived and been reassembled
        req.on('end', () => {
          console.log('✅ File transfer complete!');
          res.writeHead(200);
          res.end('Upload successful!');
        });
      }
    });

    server.listen(3000, () => console.log('Listening on port 3000...'));
    ```
  </div>
</CodeTabs>

<ConceptBlock type="tip" title="Why is this important?">
  Because data travels in chunks, your Node.js server can start processing a 5GB video upload instantly (e.g., streaming it to AWS S3) without needing 5GB of RAM to hold the entire file in memory first!
</ConceptBlock>
