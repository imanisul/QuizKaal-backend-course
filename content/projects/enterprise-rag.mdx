## The Enterprise Requirements

Building a toy RAG system is easy. Building one for an enterprise is hard. You must solve three major problems:

1. **Access Control:** The CEO and the intern are both asking the HR bot questions. The CEO should get answers based on confidential executive documents. The intern should not.
2. **Citations:** The AI says "Policy 4B allows remote work." Where did it get that? Enterprise users need proof.
3. **Conversational Memory:** Users ask follow-up questions ("What about part-time employees?"). The system needs to remember the context.

## 1. Access Control in Vector Search

You cannot enforce access control *after* retrieval (by filtering the results), because if the top 10 vector results are confidential, and you filter them out, you are left with 0 results for the user, even though relevant non-confidential documents exist further down the list.

**Access control must happen DURING the vector search using Metadata Filtering.**

```javascript
import { Pinecone } from "@pinecone-database/pinecone";
import { PineconeStore } from "@langchain/pinecone";

// 1. During Indexing: Tag documents with access roles
const documents = [
  { 
    pageContent: "Executive bonuses are capped at 50%.", 
    metadata: { doc_id: "doc_1", roles_allowed: ["admin", "executive"] }
  },
  { 
    pageContent: "Standard remote work policy.", 
    metadata: { doc_id: "doc_2", roles_allowed: ["admin", "executive", "employee"] }
  }
];

// 2. At Query Time: Filter by the user's role
async function searchForUser(query, userRole) {
  const vectorStore = await PineconeStore.fromExistingIndex(
    new OpenAIEmbeddings(),
    { pineconeIndex: index }
  );
  
  const results = await vectorStore.similaritySearch(query, 5, {
    roles_allowed: { $in: [userRole] } // Pinecone metadata filter
  });
  
  return results;
}
```

## 2. Generating Citations

To generate citations, the LLM must be explicitly instructed to cite the `doc_id` or source name from the metadata.

```javascript
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { createStuffDocumentsChain } from "langchain/chains/combine_documents";

const prompt = ChatPromptTemplate.fromTemplate(`
  You are an enterprise AI assistant. Answer the user's question based ONLY 
  on the provided context.
  
  CRITICAL INSTRUCTION: You must cite the source for every claim you make.
  Append [Source: {source_name}] to the end of sentences that rely on a document.
  
  Context:
  {context}
  
  Question: {question}
`);

// When formatting the context, we must include the metadata!
const formatDocs = (docs) => {
  return docs.map(doc => 
    `Source Name: ${doc.metadata.source}\nContent: ${doc.pageContent}`
  ).join("\n\n---\n\n");
};

// Example LLM Output:
// "Employees receive 20 days of PTO per year [Source: Employee_Handbook_v2.pdf]."
```

## 3. Conversational Memory (Follow-ups)

If a user asks "What is the PTO policy?" and then follows up with "Does it roll over?", a pure RAG system fails because "Does it roll over?" contains no semantic keywords about PTO.

The solution is to **Rewrite the Query** using the conversation history before searching the vector database.

```javascript
import { createHistoryAwareRetriever } from "langchain/chains/history_aware_retriever";
import { MessagesPlaceholder } from "@langchain/core/prompts";

// 1. The Prompt that rewrites the user's question
const contextualizeQPrompt = ChatPromptTemplate.fromMessages([
  ["system", "Given a chat history and the latest user question, formulate a standalone question that can be understood without the chat history. Do NOT answer the question, just reformulate it."],
  new MessagesPlaceholder("chat_history"),
  ["human", "{input}"]
]);

// 2. Wrap your retriever
const historyAwareRetriever = await createHistoryAwareRetriever({
  llm: model,
  retriever: vectorStore.asRetriever(),
  rephrasePrompt: contextualizeQPrompt,
});

// HOW IT WORKS:
// User: "Does it roll over?"
// History: [Human: "What is the PTO policy?", AI: "You get 20 days."]
// 
// LLM Rewrites Query To -> "Does the 20 days of PTO roll over to the next year?"
// 
// The rewritten query is sent to the Vector DB for highly accurate retrieval!
```

## 4. Putting it together: The Enterprise Pipeline

```javascript
import { createRetrievalChain } from "langchain/chains/retrieval";

// 1. History-aware retriever (handles follow-ups)
const retriever = await createHistoryAwareRetriever({
  llm: model,
  retriever: userScopedRetriever, // Filtered by user role (ACL)
  rephrasePrompt: contextualizeQPrompt,
});

// 2. Document combination chain (handles citations)
const combineDocsChain = await createStuffDocumentsChain({
  llm: model,
  prompt: citationPrompt,
});

// 3. Final execution chain
const conversationalRetrievalChain = await createRetrievalChain({
  retriever,
  combineDocsChain,
});

// 4. Execution
const response = await conversationalRetrievalChain.invoke({
  chat_history: memory.getMessages(),
  input: "Does it roll over?"
});
```
